The process:

  • First, message me with which kind of drawing you'd like, and send some refs / images of your character. If u have a specific idea for the drawing and/or a background in mind, let me know! You can even provide some reference images or moodboards for this if you'd like, it would help a lot :) Or you can let me have creative freedom with it, up to you!
  • Once I have a good idea of what u want, I'll ask you for an email address and I'll send u a PayPal invoice to pay for the commission. I currently only have PayPal set up, so I can't take any other forms of payment, sorry!
  • I'll send progress as I work on the art. Usually I'll send a rough sketch first, then a refined drawing w/ colour (no background), and finally the end result. You can ask for changes along the way if you'd like! Any big changes can only be done when the drawing's in the rough sketch phase, though.
  • Once the drawing's done I'll send u a Google Drive link to download the .png file of it. I'll post the drawing on my socials, but u can ask for it not to be posted if u wish. I'll double check with you before I post it, of course. If u wanna post it yourself somewhere, please give me credit!
